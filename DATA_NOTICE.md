# Data notice

The palette data included in this project — the 152 foundation colors,
approximately 3,400 color sets and the scheme/mood groupings — originates from
**Palette Picker** by Lightdream Design (© 1995–1997 Lightdream Design), which
was itself adapted from the *Color Harmony* series published by Rockport
Publishers.

This data was recovered through clean-room analysis of the original program for
the purpose of software preservation.  The author of Hue Harbor does not claim
ownership of this data and makes no representation about its copyright status.
It is included here solely for compatibility with, and preservation of, the
original Palette Picker experience.
